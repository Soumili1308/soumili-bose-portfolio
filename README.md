# Soumili Bose Portfolio

Vanilla HTML, CSS and JavaScript portfolio inspired by the supplied Figma-style design.

## Run
Open `index.html` directly in Chrome/Edge/Firefox. No Node.js, React or build step is required.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — navigation, theme toggle, scrolling and print-to-PDF resume action
- `assets/` — optional assets

## Important
The four project buttons currently point to `https://github.com/Soumili1308` because individual repository URLs were not provided. Replace each `href` in `index.html` with the correct repository URL.

The Download Resume button opens the browser print dialog so you can choose **Save as PDF**. This makes it work even without a separate PDF file.
